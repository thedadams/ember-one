# Ember One for rootshell

This port provides the dark Ember One palette as a rootshell custom theme.

## Install

Download or copy [`ember-one.json`](ember-one.json) to your device. In
rootshell, open the theme picker, import the file as a custom theme, and select
**Ember One**.

See rootshell's [project documentation][rootshell] for its custom-theme
features and supported platforms.

[rootshell]: https://github.com/kitknox/rootshell
