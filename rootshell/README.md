# Ember One for rootshell

This port provides the dark and light Ember One palettes as separate rootshell
custom themes.

## Install

Download or copy [`ember-one-dark.json`](ember-one-dark.json) and
[`ember-one-light.json`](ember-one-light.json) to your device. In rootshell,
open the theme picker and import each file as a custom theme. Select **Ember One
Dark** or **Ember One Light**, or assign them as rootshell's day and night
themes for automatic switching.

See rootshell's [project documentation][rootshell] for its custom-theme
features and supported platforms.

[rootshell]: https://github.com/kitknox/rootshell
