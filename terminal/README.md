# Ember One for Terminal.app

Terminal.app stores each appearance as a separate profile, so this port ships
`Ember One Dark.terminal` and `Ember One Light.terminal`.

Import either profile by double-clicking the file, or in Terminal choose
**Settings → Profiles**, open the action menu, and choose **Import**.

The profiles retain the original Ember One font, window, shell-command, and
behavior settings. The light profile uses warm ivory surfaces and
contrast-adjusted Ember One colors.
