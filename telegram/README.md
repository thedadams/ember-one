# Ember One for Telegram

Ember One is available as two Telegram cloud themes. Telegram selects the
platform-specific version of a cloud theme when its install link is opened in
an official app.

| Variant | Install | Theme page |
| --- | --- | --- |
| Light | [Apply Ember One Light][light-install] | [Open in the theme editor][light-editor] |
| Dark | [Apply Ember One Dark][dark-install] | [Open in the theme editor][dark-editor] |

## Android

1. Open the [light][light-install] or [dark][dark-install] install link on the
   Android device.
2. If the link opens in a browser, tap **View in Telegram** or approve the
   prompt to open the Telegram app.
3. Review the theme preview in Telegram, then tap **Apply Theme**.
4. To switch themes later, open **Settings > Chat Settings** and select the
   desired theme.

## iPhone and iPad

1. Open the [light][light-install] or [dark][dark-install] install link in
   Safari or from a Telegram message.
2. Tap **Open** if iOS or iPadOS asks for permission to launch Telegram.
3. Review the preview, then tap **Apply Theme**.
4. To switch themes later, open **Settings > Appearance** in Telegram.

## Telegram Desktop on Windows, Linux, and macOS

These steps apply to the cross-platform Telegram Desktop app, including the
version available from [desktop.telegram.org][desktop].

1. Open the [light][light-install] or [dark][dark-install] install link on the
   computer.
2. Allow the browser to open Telegram Desktop. If more than one Telegram app is
   installed, choose **Telegram Desktop**.
3. Inspect the preview and select **Apply This Theme**.
4. To switch themes later, open **Settings > Chat Settings**.

## Telegram for macOS

These steps apply to the native macOS app, which is separate from Telegram
Desktop.

1. Open the [light][light-install] or [dark][dark-install] install link on the
   Mac.
2. Allow the browser to open **Telegram**. If prompted to choose between apps,
   select the native macOS client.
3. Review the preview and apply the theme.
4. To switch themes later, open **Settings > Appearance**.

## If an install link does not open the app

Copy the complete install link, send it to **Saved Messages**, and open it from
inside Telegram. Make sure the official app is current if Telegram reports
that the theme is unsupported.

Cloud-theme updates are delivered automatically after the theme author saves
them. See Telegram's [official cloud-theme documentation][themes] for theme
links, platform variants, and settings locations.
